# Benchmark row dossiers

This directory is the working set for SecureBench's row-by-row benchmark conversion review.

- [`TerminalBench/`](TerminalBench/) contains **89** Terminal-Bench 2.0 row dossiers.
- [`DeepSWE/`](DeepSWE/) contains **113** DeepSWE row dossiers.
- [`CHECKLIST.md`](CHECKLIST.md) tracks which rows have been reviewed.

These initial dossiers document goals and existing tests only. They deliberately contain no conversion recommendation. Future decisions belong in each file's **Future conversion notes** section.

The inventories are generated from pinned official source snapshots. Condensed instructions and mechanically extracted test names are navigation aids; the linked verifier source remains authoritative.

The proposed common author-facing schema and twelve concrete converted-row
examples are documented in
[`../split-verification-row-schema.md`](../split-verification-row-schema.md).
