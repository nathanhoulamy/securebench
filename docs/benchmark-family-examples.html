SecureBench Practical Family Examples (Revised)

Concrete example rows for each benchmark family, updated to keep public assets separate from evaluator inputs and hidden scoring data.

Public: visible to harness/agent evaluation_inputs: verifier/runtime only hidden: trusted scorer only Blank means inherited or unused
Back to Revised Standard Open Tester YAML Standard

Example Assumption

Each table is a flattened view of rows normally stored as JSONL or Parquet. Top-level assets[] are public. Checker files, hidden tests, expected state, reference artifacts, and rubrics live under eval.* and are compiled by SecureBench into evaluation_inputs or hidden.
